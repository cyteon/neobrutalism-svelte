# Neobrutalism Svelte

This project is a Svelte port of [neobrutalism-components](https://github.com/ekmas/neobrutalism-components).
Installation of the components is done with the shadcn-svelte cli

## Developing locally
1. Install the deps with `npm i`
2. Run it with `npm run dev`
3. After any components changes, run `npm run generate-json`
